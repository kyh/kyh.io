# kyh.io

[kyh.io](https://kyh.io)

> Personal website and portfolio.

## Stack

- Framework - [Next.js](https://nextjs.org/)
- Physics - [Matter.js](https://brm.io/matter-js/)
- 3D - [three.js](https://threejs.org/) (the `/showcase` city)
- Styling - [Tailwind CSS v4](https://tailwindcss.com)
- Multiplayer - [@vibedgames/multiplayer](https://github.com/kyh/vibedgames/tree/main/packages/multiplayer) on the shared vibedgames party server
- Hosting - [Vercel](https://vercel.com)

## Development

```bash
pnpm install
pnpm dev:kyh
```

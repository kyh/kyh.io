# BooBounty

> Honeypot pentesting for AI companies.

A meme site. Taiwanese 7s who read r/agi try to seduce your staff; if it works, your board hears about it. Static for now: the contact form only acknowledges, nothing is sent.

Live at [boobounty.com](https://www.boobounty.com).

## Stack

- Framework - [Next.js](https://nextjs.org/)
- Styling - [Tailwind CSS v4](https://tailwindcss.com)

## Development

```bash
pnpm install
pnpm dev:boobounty   # → http://localhost:3006
```

# BooBounty

> Honeypot pentesting for AI companies.

A meme site. Taiwanese 7s who read r/agi try to seduce your staff; if it works, your board hears about it. A tabloid ad: a newspaper page whose lead photo, printed in halftone, is a honey jar you can turn, with a dipper you carry to drizzle honey around it. Kevin left his badge on the floor.

Live at [boobounty.com](https://www.boobounty.com).

## Stack

- Framework - [Next.js](https://nextjs.org/)
- 3D - [three.js](https://threejs.org/), procedural, no model files
- Styling - [Tailwind CSS v4](https://tailwindcss.com)

## Development

```bash
pnpm install
pnpm dev:boobounty   # → http://localhost:3006
```
